# Data-Science-Portfolio
A portfolio of data science and data analysis projects using datasets from Kaggle, covering data cleaning, exploratory data analysis, visualization, statistical analysis, and machine learning.

## 🎓 Student Performance Analysis Project
Analysis of Student Exam Performance and Demographic Factors

***Summary:*** An end-to-end Exploratory Data Analysis (EDA) project examining the demographic, social, and economic factors (gender, parental education level, preparatory courses, nutritional conditions) that influence students' exam success.

### ***Key Findings:***

**- Educational Support:** The average overall performance of students who completed exam preparation courses was 11.7% higher than that of students who did not take the courses (72.67 vs. 65.04). 

**- Socio-Economic Impact:** Students with access to standard lunch options outperformed peers receiving free or reduced-price meals by 10–12 points across all subjects. 

**- Strong Correlation:** A near-perfect positive linear relationship (0.95) was identified between reading and writing scores.

**- Technologies Used:** Python, Pandas, NumPy, Seaborn, Matplotlib, Plotly, Kaggle API.

**- Skills Gained:** Data visualization, statistical data analysis, correlation analysis, and insight generation.
